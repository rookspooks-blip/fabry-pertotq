Часть 0. Карта программы

0.1. Что делает программа одной фразой

Программа берёт параметры интерферометра (длину волны λ, зазор d, отражение зеркал R и другие), считает по формулам физики, сколько света проходит через прибор, и рисует три картинки: график пропускания T(λ), картину колец и разрез колец по радиусу. Потом она сама «меряет» получившиеся картинки, как это сделал бы человек с линейкой, и сравнивает результат с формулами. В режиме лабораторной работы часть параметров скрыта, и студент находит их сам по своим измерениям.

0.3. Как запустить из исходников

pip install -r requirements.txt     # один раз: ставит numpy и PyQt6
python run.py                       # запуск
python -m fabry_perot               # то же самое, другим способом
python -m pytest tests              # запуск проверок (нужен pip install pytest)

pip — программа, которая скачивает библиотеки Python из интернета (с сайта PyPI) и ставит их. Ключ -r файл значит «поставь всё, что перечислено в этом файле».

0.4. Что происходит при запуске, по шагам

  1. Python выполняет run.py. Там одна строчка: импортировать функцию main из fabry_perot/app.py и вызвать её.
  2. При импорте app.py по цепочке загружаются все модули: qt.py выбирает PyQt6 или PyQt5, theme.py создаёт объект темы и так далее.
  3. main() создаёт приложение Qt (create_app), затем главное окно MainWindow(). Конструктор окна строит все кнопки и графики и вызывает restore(): тот достаёт параметры прошлого запуска и делает первый расчёт recalc().
  4. window.show() показывает окно, app.exec() запускает «цикл событий»: программа ждёт действий пользователя и реагирует на них (часть 6.2). Пока окно открыто, выполнение «висит» внутри app.exec().
  5. Когда окно закрывают, вызывается closeEvent: он сохраняет параметры, после чего app.exec() возвращает код завершения, и sys.exit заканчивает программу.

Часть 1. Python сверх основ

Всё, что в программе встречается помимо переменных, циклов, условий и простых функций

1.1. Модули и пакеты

Модуль — это любой файл .py. Пакет — папка с модулями, в которой лежит файл __init__.py (он может быть и пустым). Наша папка fabry_perot — пакет.

Команда import выполняет файл модуля один раз (при первом импорте) и даёт доступ к тому, что в нём определено. Второй импорт того же модуля ничего не выполняет заново — Python помнит уже загруженные модули в словаре sys.modules. Поэтому объект THEME в theme.py существует в одном экземпляре, сколько бы модулей его ни импортировало.

import math                          # весь модуль; обращение: math.sqrt(2)
import numpy as np                   # весь модуль под коротким именем: np.sqrt(2)
from math import sqrt                # одно имя из модуля: sqrt(2)
from .qt import Qt, QtWidgets        # точка = «из этого же пакета» (относительный импорт)
from . import APP_TITLE              # имя из __init__.py этого пакета
from fabry_perot.app import main     # абсолютный импорт: пакет.модуль

Относительный импорт (с точкой) работает только внутри пакета. Внутри fabry_perot/ все модули импортируют друг друга с точкой: так пакет можно переименовать или переложить, и ничего не сломается. А run.py лежит снаружи пакета, поэтому пишет полное имя fabry_perot.app.

if __name__ == "__main__"

У каждого модуля есть переменная __name__. Если файл запустили напрямую (python run.py), она равна строке "__main__"; если его импортировали — имени модуля. Условие в конце run.py значит «запускай окно, только если меня запустили, а не импортировали».

__main__.py и python -m

Команда python -m fabry_perot говорит: «найди пакет fabry_perot и выполни его файл __main__.py». Ключ -m (module) удобен тем, что пакет находится по обычным правилам импорта, и относительные импорты внутри него работают.

Строка документации

Строка в тройных кавычках в самом начале модуля, функции или класса — docstring. Python сохраняет её (её показывает help(функция)), на работу программы она не влияет. В программе у каждой функции есть такая строка: что делает функция и почему именно так.

1.2. Классы и объекты

Класс — это чертёж. Объект — изделие по чертежу. У изделия есть свои данные (атрибуты) и то, что оно умеет делать (методы). Например, чертёж «строка параметра» ParamRow один, а изделий по нему девять: для λ, d, Δd, R, A, n, f, экрана и δλ. У каждого свой ползунок и своё поле.

class Counter:
    step = 1                          # атрибут класса: общий для всех объектов

    def __init__(self, start):        # конструктор: вызывается при создании объекта
        self.value = start            # атрибут объекта: у каждого свой

    def tick(self):                   # метод
        self.value += self.step

c = Counter(10)                       # создание: Python вызывает __init__(c, 10)
c.tick()                              # то же, что Counter.tick(c)
print(c.value)                        # 11
  • self — сам объект. Python подставляет его первым аргументом автоматически: вызов c.tick() превращается в Counter.tick(c). Через self.имя объект хранит свои данные между вызовами методов.
  • __init__ — метод, который Python вызывает сам при создании объекта. Здесь задаются начальные значения атрибутов. Конструктор MainWindow.__init__ занимает 60 строк: он строит всё окно.
  • Атрибут класса записан прямо в теле класса, без self. Пример: ParamRow.STEPS = 1000 — у всех ползунков по 1000 положений. У StepSpin атрибут класса stepping = False служит значением по умолчанию; когда метод пишет self.stepping = True, у объекта появляется свой атрибут, который «заслоняет» общий.

Наследование

Запись class Plot(QtWidgets.QWidget): значит: «Plot — это QWidget (элемент окна Qt), плюс мои дополнения». Plot получает все методы QWidget (показаться, изменить размер, перерисоваться…) и добавляет свои. Если в Plot написать метод с тем же именем, что у QWidget, он переопределяет (заменяет) родительский. Именно так программа рисует свои графики: Qt, когда нужно нарисовать виджет, вызывает его метод paintEvent; у QWidget он ничего не рисует, а у Plot — рисует график.

super() — «родительский класс». super().stepBy(steps) вызывает настоящий метод QDoubleSpinBox.stepBy, который и меняет число. Наш метод только оборачивает его: ставит флажок до и снимает после. Пока флажок стоит, поле шлёт сигнал «значение изменилось», и строка параметра видит, что это был шаг стрелкой (часть 8.3). В каждом конструкторе наследника первой строкой стоит super().__init__(): сначала должна отработать «родительская» подготовка объекта (у виджета Qt это создание настоящего окна-элемента внутри библиотеки), а потом уже наша.

Особые методы и @property

  • __getitem__ — метод, который Python вызывает для записи с квадратными скобками. Благодаря ему пишется THEME["bg"], как у словаря, хотя THEME — объект. Внутри он просто берёт значение из текущей палитры self.p.
  • @property — декоратор (строка с @ перед функцией, которая «оборачивает» функцию). Он превращает метод в атрибут «только для чтения»: пишется THEME.dark без скобок, а на самом деле каждый раз выполняется функция и проверяет имя палитры.
  • Объект THEME = Theme() создаётся один раз при загрузке модуля. Все виджеты берут цвета из него в момент рисования. Сменить тему — значит сменить THEME.p и попросить окно перерисоваться.

Ещё особые методы, встречающиеся в программе, — это методы Qt с окончанием Event (paintEvent, mousePressEvent…). Они не особые для Python, но особые для Qt: Qt сам вызывает их, когда происходит событие (часть 6.6).

Простые классы-«записи»

Некоторые классы нужны только чтобы держать вместе несколько значений: Curve (формула кривой, цвет, имя, шум), Series (название задания, подписи осей, подсказка…), Variant (скрытые величины варианта). Можно было бы хранить это в словарях, но с классом обращение короче (s.title вместо s["title"]) и можно добавить методы (Curve.reading, Variant.realism).

1.3. Функции как значения

В Python функция — такой же объект, как число или список. Её можно положить в переменную, передать в другую функцию, вернуть из функции. Главное отличие: f — это сама функция, а f() — результат её вызова.

В программе это используется постоянно:

  • ParamRow(grid, row, spec, self.param_changed) — строке параметра передаётся метод окна. Строка запоминает его в self.on_change и вызывает self.on_change(self.key, smooth), когда значение изменилось. Строка ничего не знает об окне, она знает только «кого позвать».
  • Journal(self.context, …) — журнал получает функцию, которая возвращает текущие параметры окна.
  • button.clicked.connect(self.save_png) — кнопке передаётся метод, который надо вызвать по щелчку (часть 6.5).
  • Curve(value, span, …) — кривая на графике хранит не точки, а две функции: как посчитать значение в любой точке и как найти минимум и максимум на отрезке.

Связанный метод. self.param_changed (без скобок) — это метод, уже «привязанный» к конкретному окну. Когда его позже вызовут как on_change("d", True), Python сам подставит нужный self.

lambda

lambda аргументы: выражение — короткая безымянная функция в одну строку. Запись lambda x: x * 2 означает то же, что

def без_имени(x):
    return x * 2

Пример из программы: key=lambda s: abs(math.log(s / raw)) в fmt.ticks — функция, по которой min выбирает «самый близкий» шаг делений.

Замыкания

Функция, определённая внутри другой функции, видит переменные внешней — даже после того, как внешняя закончилась. Это называется замыкание.

Здесь value и span пользуются переменными d, n, F, tmax, blur, share, wl из recalc. Функции «уносят» эти значения с собой в объект Curve, и график потом вызывает их, когда нужно нарисовать кривую при любом масштабе.

lambda в цикле. Замыкание запоминает не значение, а саму переменную. Если в цикле написать button.clicked.connect(lambda: self.apply_preset(values)), то все кнопки после цикла будут видеть последнее значение values. Поэтому в программе написано lambda _, v=values, s=dlam: self.apply_preset(v, s): значения по умолчанию аргументов вычисляются в момент создания функции, так что у каждой кнопки свои v и s. Первый аргумент _ — это checked, который шлёт сигнал clicked; он не нужен, а подчёркивание по договорённости означает «не используется». Тот же приём в журнале: def value(x, a=a, b=b).

Ещё одна ловушка: список, содержащий сам себя

В recalc написано curves.append(self.sum_curve(list(curves), sigma)). Функция суммы складывает все кривые списка. Если передать сам список curves, то после append в нём окажется и кривая суммы, и она попробует сложить сама себя — бесконечно (ошибка RecursionError). list(curves) делает копию списка в момент вызова, и кривая суммы видит только две исходные кривые.

1.4. Распаковка, аргументы, словари

key, name, unit, lo, hi, value, decimals, step, tip, log = spec   # 10 элементов кортежа → 10 переменных
a, b = b, a                                                          # обмен значений
module, *names = "window.MainWindow.recalc".split(".")               # module="window", names=[…, …]
for button, values, dlam in self.preset_buttons: ...                  # распаковка прямо в цикле
for i, (_, name) in enumerate(TILES): ...                             # вложенная распаковка
  • Звёздочка при распаковке собирает «всё остальное» в список.
  • *args в определении функции собирает лишние позиционные аргументы в кортеж: def schedule(self, *args) можно вызвать с любым числом аргументов — это нужно, потому что разные сигналы Qt передают разное число значений, а функции они не нужны.
  • Звёздочка при вызове раскладывает список в отдельные аргументы: LabDialog(self, *self.student) то же, что LabDialog(self, self.student[0], self.student[1]).
  • Две звёздочки раскладывают словарь в именованные аргументы: p.chromium.launch(**{"executable_path": exe}) = launch(executable_path=exe).
  • Именованные аргументы и значения по умолчанию: def num(x, digits=4) можно вызвать как num(x) или num(x, 3), или num(x, digits=3).
  • Словарь с добавками: dict(BASE, lam=632.8, d=5.0, R=0.9) — копия словаря BASE, в которую добавлены (или заменены) ключи. Так все примеры получают общие значения n = 1, f = 200 и т. д.
  • dict.get(key, default) — значение по ключу или default, если ключа нет (без ошибки). dict.pop(key, None) — удалить ключ, если он есть.

  • Минус - заменяется на настоящий типографский минус − (он длиннее дефиса).
  • isinstance(x, (int, np.integer)) — проверка типа: целое число Python или целое numpy.

Unicode. Строки Python хранят любые символы: λ, δ, ², ₁, «», ≈, ⌀. Их можно писать прямо в коде, потому что файлы сохранены в кодировке UTF-8.

Часть 2. numpy

Библиотека для быстрых вычислений сразу над тысячами и миллионами чисел

2.1. Зачем numpy

Обычный цикл Python обрабатывает около 10–30 миллионов простых операций в секунду: каждая операция проверяет типы, создаёт объекты и т. п. numpy хранит числа сплошным блоком памяти одного типа и обрабатывает весь блок кодом на C за одну команду. Получается в 50–200 раз быстрее. Картинка колец 700 × 700 — это почти полмиллиона пикселей; обойти их циклом Python — около секунды, numpy — несколько миллисекунд.

import numpy as np
x = np.linspace(0, 1, 5)       # массив [0.  , 0.25, 0.5 , 0.75, 1.  ]
y = np.sin(x) * 2 + 1          # одна строка — вычисление для всех 5 чисел сразу
# без numpy пришлось бы писать:
y = [math.sin(v) * 2 + 1 for v in xs]

Такой стиль называется векторизация: вместо цикла «для каждого числа» пишется формула для целого массива. Функции physics.py написаны так, что работают и с одним числом, и с массивом: в phase(lam, d, n) можно передать массив длин волн и получить массив фаз.

2.2. Массив: форма и тип

  • Форма (shape) — размеры массива. Одномерный из 5 чисел: (5,). Картинка 400 × 300: (300, 400) — сначала строки (высота), потом столбцы (ширина).
  • Тип (dtype) — какие числа внутри. Все элементы одного типа:
    • float64 — обычные дробные числа (≈ 16 значащих цифр), тип по умолчанию;
    • float32 — дробные с ≈ 7 цифрами, вдвое меньше памяти и быстрее; используется для растеризации графика, где точность пикселя не нужна;
    • uint8 — целые 0…255 (один байт) — степень прозрачности пикселя;
    • uint32 — целые 0…4 294 967 295 (четыре байта) — цвет пикселя целиком;
    • intp — целые для номеров элементов (индексов).
  • a.astype(np.uint8) — новый массив другого типа (дробная часть отбрасывается, поэтому перед этим прибавляют 0,5 — так получается округление).

+ − * / ** между массивами одной формы действуют попарно: a * b — массив произведений. Между массивом и числом — число применяется к каждому элементу. Функции numpy тоже поэлементные:

2.5. Индексы, срезы, маски

y = np.array([0, 3, 1, 5, 2])
y[1:-1]            # [3, 1, 5]   — без первого и последнего («середина»)
y[:-2]             # [0, 3, 1]   — «левые соседи» середины
y[2:]              # [1, 5, 2]   — «правые соседи» середины

y[[3, 1]]          # [5, 3]      — выбор по списку номеров («причудливые индексы»)
y[y > 1]           # [3, 5, 2]   — выбор по маске
np.flatnonzero(y > 1)   # [1, 3, 4] — номера, где условие верно

Так find_peaks ищет максимумы без цикла: точка — максимум, если она больше левого соседа и не меньше правого. Сравнение трёх сдвинутых срезов проверяет это условие сразу для всех точек, flatnonzero даёт их номера, а + 1 поправляет сдвиг (срез y[1:-1] начинается с элемента 1).

Выбор по массиву номеров table[index] работает и для двумерного index: результат имеет форму index, а значения берутся из table. Так картинка колец получает цвет каждого пикселя по его расстоянию до центра (часть 7.9). Запись grid[np.arange(len(center)), best] берёт из каждой строки таблицы grid элемент со своим номером best.

2.6. Broadcasting — «растягивание» форм

Если сложить столбец из 3 чисел и строку из 4 чисел, numpy получит таблицу 3 × 4: каждый элемент столбца сложится с каждым элементом строки. Это и есть broadcasting. Так строятся двумерные картинки без двойного цикла.

rows = np.arange(3)[:, None]      # форма (3, 1): столбец [[0], [1], [2]]
cols = np.arange(4)[None, :]      # форма (1, 4): строка [[0, 1, 2, 3]]
rows * 10 + cols                  # форма (3, 4):
# [[ 0,  1,  2,  3],
#  [10, 11, 12, 13],
#  [20, 21, 22, 23]]

[:, None] добавляет ось длины 1 справа (из строки делает столбец), [None, :] — слева. Правило: оси длины 1 «растягиваются» до длины соответствующей оси другого массива.

Примеры в программе:

  • RingView.make_image: np.hypot(c[None, :] + cx, c[:, None] + cy) — расстояние от центра колец для каждого пикселя квадратной картинки: c[None, :] — координата x столбца, c[:, None] — координата y строки.
  • Plot.draw_curve: rows — столбец номеров строк пикселей, top и bottom — строки «верх и низ кривой в каждом столбце»; np.minimum(rows + 1, bottom + half) даёт сразу всю картинку.
  • measure_rings: center[:, None] + step * offsets[None, :] — вокруг каждого из сотни найденных колец сетка из 33 точек, всего таблица 100 × 33.

2.7. Сводные функции и форма

  • a.max(), a.min(), a.sum() — по всему массиву.
  • a.max(axis=1) — по каждой строке отдельно (ось 1 — вдоль строки). Результат — столбец максимумов.
  • np.argmax(a, axis=1) — номер наибольшего элемента в каждой строке.
  • a.ravel() — вытянуть таблицу в одну строку; a.reshape(форма) — обратно в таблицу.
  • a.copy() — копия. Срез a[:10] в numpy — не копия, а «окно» в тот же массив: изменения в нём меняют исходный массив. Поэтому в measure_rings написано peaks[:refine].copy().

Битовые операции для цвета

Цвет пикселя в Qt — одно 32-битное число: 8 бит прозрачности, 8 красного, 8 зелёного, 8 синего: 0xAARRGGBB. Собрать его из четырёх чисел 0…255 можно сдвигами: (a << 24) | (r << 16) | (g << 8) | b. Сдвиг << 16 умножает на 2¹⁶ — число «переезжает» на 16 бит влево, а | (побитовое «или») складывает части, не мешая друг другу. Так сделаны color_table и таблица цветов колец.

2.9. Дробные числа в компьютере

  • Число float64 хранит около 16 значащих цифр. 0.1 + 0.2 даёт 0.30000000000000004: десятичные дроби не всегда записываются точно в двоичном виде. Поэтому числа сравнивают не на равенство, а с допуском: abs(a − b) < 1e-12, или в тестах pytest.approx.
  • Потеря точности при вычитании близких чисел. Порядок интерференции в центре m₀ = 2nd/λ ≈ 15 800. Если считать sin²θ = n² − (mλ/2d)², вычитаются два числа около 1, отличающиеся в 5–6 знаке, и половина значащих цифр теряется. ring_radii переписывает формулу как a·(m₀ − m)·(n + m·a) (это разность квадратов x² − y² = (x − y)(x + y)): разность m₀ − m считается точно, и радиусы получаются верными до последних знаков.
  • nan («не число») получается, например, из 0/0 или √(−1) в numpy; inf — бесконечность. math.isfinite(x) проверяет, что x — обычное число.
  • Порог 1e-9 в fmt.ticks (math.ceil(lo / step − 1e-9)) защищает от того, что 0,14 / 0,02 в компьютере равно 7,000000000000001, и округление вверх дало бы 8 вместо 7 — первое деление оси пропало бы. Небольшой запас убирает такие ошибки.

Часть 3. Физика

От того, что такое волна, до каждой формулы в physics.py

3.1. Свет — волна

Свет — это колебания электрического и магнитного поля, которые бегут в пространстве со скоростью c ≈ 3·10⁸ м/с. Если «сфотографировать» волну, поле вдоль луча меняется как синусоида. Расстояние между соседними гребнями — длина волны λ. От длины волны зависит цвет.

  • Длина волны λ видимого света — от 380 нм (фиолетовый) до 780 нм (тёмно-красный). 1 нм (нанометр) = 10⁻⁹ м, 1 пм (пикометр) = 10⁻¹² м = 0,001 нм, 1 фм (фемтометр) = 10⁻¹⁵ м. Гелий-неоновый лазер светит на 632,8 нм (красный), зелёная лазерная указка — на 532 нм, натриевая лампа — на двух линиях 589,0 и 589,6 нм (жёлтый).
  • Частота ν — сколько колебаний в секунду в данной точке: ν = c/λ. Для 632,8 нм ν ≈ 4,74·10¹⁴ Гц.
  • Фаза — «в какой части колебания» волна находится, в радианах. Один полный период — 2π радиан (360°). Когда волна проходит путь L, её фаза меняется на 2πL/λ: каждая длина волны пути — ещё один полный оборот.
  • Глаз и приёмники чувствуют не само поле, а интенсивность — среднюю мощность, пропорциональную квадрату амплитуды поля. Колебания 10¹⁴ раз в секунду не может отследить ни один прибор.

3.2. Интерференция

Когда в одну точку приходят две волны одинаковой частоты, их поля складываются. Результат зависит от разности фаз Δφ:

  • Δφ = 0, 2π, 4π… — гребень на гребень, волны усиливают друг друга (максимум);
  • Δφ = π, 3π… — гребень на впадину, волны гасят друг друга (минимум).

Для двух одинаковых волн интенсивность I = 2I₀(1 + cos Δφ): от 0 до 4I₀. Это и есть интерференция. Разность фаз обычно возникает из-за разности хода — одна волна прошла путь длиннее другой на Δ, тогда Δφ = 2πΔ/λ.

Как складывать волны: комплексные числа

Складывать синусоиды с разными фазами неудобно. Физики записывают волну как комплексное число $E = a\,e^{i\varphi}$ — стрелку длины a, повёрнутую на угол φ. Складывать волны — значит складывать стрелки, а интенсивность — квадрат длины получившейся стрелки: $I = |E|^2$. Этого достаточно, чтобы понять вывод ниже. Тест test_airy_matches_sum_of_beams прямо так и делает: складывает 800 стрелок с помощью комплексных чисел numpy (1j — мнимая единица в Python) и сравнивает с формулой.

3.3. Устройство интерферометра

Два плоских частично прозрачных зеркала стоят параллельно на расстоянии d. Каждое зеркало отражает долю R интенсивности, поглощает долю A и пропускает долю 1 − R − A. Свет входит через первое зеркало и много раз ходит между зеркалами. На каждом отражении от второго зеркала часть света выходит наружу. Выходящие лучи параллельны, линза собирает их в одну точку своего фокального экрана, и там они интерферируют.

Каждый следующий выходящий луч прошёл зазор ещё два раза (туда и обратно), поэтому отстаёт от предыдущего на разность хода Δ = 2nd·cos θ′, где θ′ — угол луча внутри зазора, n — показатель преломления среды в зазоре (воздух ≈ 1, стекло ≈ 1,5). Показатель преломления показывает, во сколько раз свет в среде медленнее, чем в вакууме; путь L в среде эквивалентен пути nL в вакууме (оптический путь).

3.4. Формула Эйри: вывод

Пусть амплитуда входящей волны 1. Амплитудный коэффициент пропускания зеркала $t$ (по интенсивности $t^2 = 1 - R - A$), амплитудный коэффициент отражения $r$ ($r^2 = R$). Первый выходящий луч прошёл два зеркала: $t^2$. Второй дополнительно дважды отразился и отстал по фазе на δ: $t^2 r^2 e^{i\delta}$. Третий: $t^2 r^4 e^{2i\delta}$ и так далее. Сумма — геометрическая прогрессия со знаменателем $q = R e^{i\delta}$:

E = t^2 \left(1 + q + q^2 + \ldots\right) = \frac{t^2}{1 - R e^{i\delta}}

(сумма бесконечной геометрической прогрессии $1/(1-q)$ при $|q| < 1$). Интенсивность — квадрат модуля:

T = |E|^2 = \frac{(1-R-A)^2}{|1 - R e^{i\delta}|^2} = \frac{(1-R-A)^2}{1 - 2R\cos\delta + R^2}

Знаменатель переписывается через $\cos\delta = 1 - 2\sin^2(\delta/2)$: $1 - 2R + R^2 + 4R\sin^2(\delta/2) = (1-R)^2 + 4R\sin^2(\delta/2)$. Поделив числитель и знаменатель на $(1-R)^2$, получаем формулу Эйри:

T = \frac{T_{\max}}{1 + F\sin^2(\delta/2)},\qquad F = \frac{4R}{(1-R)^2},\qquad T_{\max} = \frac{(1-R-A)^2}{(1-R)^2}
  • Когда $\delta = 2\pi m$ (m — целое), $\sin(\delta/2) = 0$ и $T = T_{\max}$ — пик пропускания: все лучи приходят в фазе.
  • Посередине между пиками $\sin^2 = 1$ и $T_{\min} = T_{\max}/(1+F)$. Отношение $T_{\max}/T_{\min} = 1 + F$ называется контрастом. При R = 0,9 F = 360: провалы в 361 раз темнее пиков.
  • Без поглощения (A = 0) $T_{\max} = 1$: на пике проходит весь свет, хотя каждое зеркало отражает 90 %. Это не ошибка: отражённые назад волны гасят друг друга, и энергии некуда деваться, кроме как пройти.
  • С поглощением пики ниже: при R = 0,95 и A = 0,02 $T_{\max} = (0{,}03/0{,}05)^2 = 0{,}36$. Свет много раз ходит между зеркалами и каждый раз теряет долю A. max(1.0 - R - A, 0.0) защищает от R + A > 1 (зеркало не может отразить и поглотить больше 100 %).

3.5. Фаза δ и закон преломления

Разность фаз соседних лучей $\delta = 2\pi\cdot 2nd\cos\theta'/\lambda$. Удобнее выразить её через угол θ, под которым луч выходит из прибора в воздух: по закону Снеллиуса (закону преломления) $\sin\theta = n\sin\theta'$, отсюда $n\cos\theta' = \sqrt{n^2 - n^2\sin^2\theta'} = \sqrt{n^2 - \sin^2\theta}$:

\delta = \frac{4\pi d\sqrt{n^2 - \sin^2\theta}}{\lambda}

Аргумент sin_out — это sin θ. По умолчанию 0: свет идёт перпендикулярно зеркалам, и тогда δ = 4πnd/λ. Для графика T(λ) в программе берётся именно этот случай (надпись «свет падает перпендикулярно»).

3.6. Порядок интерференции

Условие пика $\delta = 2\pi m$ с формулой (2) даёт $2d\sqrt{n^2-\sin^2\theta} = m\lambda$: на удвоенной оптической толщине укладывается целое число m длин волн. Число m — порядок интерференции. В центре (θ = 0) дробный «порядок» $m_0 = 2nd/\lambda$; при λ = 632,8 нм, d = 5 мм m₀ ≈ 15 803. Функция order_at считает порядок в любой точке экрана — его показывает курсор над кольцами («m = …»).

3.7. Кольца

Если свет от протяжённого источника идёт под разными углами, у каждого угла свой δ. Условие пика выполняется на определённых углах θ_k, а из-за симметрии вокруг оси прибора одинаковый угол — это окружность. Линза с фокусным расстоянием f собирает лучи, идущие под углом θ, в точку на расстоянии $r = f\,\mathrm{tg}\,\theta$ от центра фокального экрана. Получаются концентрические светлые кольца.

  • Порядок m убывает от центра к краю (cos θ уменьшается). Первое кольцо — наибольшее целое m, меньшее m₀.
  • Для малых углов $\cos\theta \approx 1 - \theta^2/2$, $r \approx f\theta$. Подстановка в условие пика даёт
r_k^2 = \frac{f^2 n\lambda}{d}\,(k - 1 + \varepsilon)

где k — номер кольца от центра (1, 2, 3…), ε — дробная часть m₀ (0 ≤ ε < 1): насколько центр «не дошёл» до следующего кольца. Главное: квадраты радиусов растут линейно с номером, разность квадратов соседних колец одна и та же: $r_{k+1}^2 - r_k^2 = f^2 n\lambda/d$. Поэтому кольца сгущаются к краю, и поэтому в лабораторной строится график r² от k: по наклону находится λ.

Функция считает радиусы по точной формуле, без приближения малых углов: из $2d\sqrt{n^2 - s^2} = m\lambda$ получаем $s^2 = \sin^2\theta = n^2 - (m\lambda/2d)^2$, потом $\mathrm{tg}\,\theta = s/\sqrt{1-s^2}$ и $r = f\,\mathrm{tg}\,\theta$. Запись через $a(m_0 - m)(n + ma)$ — это та же разность квадратов, но без потери точности (часть 2.9). Фильтр (s2 > 0) & (s2 < 1) отбрасывает несуществующие углы.

3.8. Спектр пропускания T(λ) и область свободной дисперсии

Если зафиксировать угол (θ = 0) и менять длину волны, δ = 4πnd/λ тоже меняется, и пропускание проходит через пики. Соседние пики — это порядки m и m+1. Расстояние между ними по длине волны:

\Delta\lambda = \frac{\lambda^2}{2nd},\qquad \Delta\nu = \frac{c}{2nd}

Вывод: $m\lambda_m = 2nd$, $(m+1)\lambda_{m+1} = 2nd$; разность $\lambda_m - \lambda_{m+1} = \lambda/(m+1) \approx \lambda^2/(2nd)$. По частоте всё точно: $\nu_m = mc/(2nd)$, шаг $c/(2nd)$.

Δλ называется областью свободной дисперсии (англ. FSR — free spectral range, отсюда ключ "fsr" в коде). Смысл названия: если две линии спектра отличаются больше чем на Δλ, пик одной попадёт на соседний пик другой, и прибор их спутает («перекрытие порядков»). При d = 5 мм, λ = 632,8 нм Δλ ≈ 40 пм — очень маленький интервал: интерферометр Фабри — Перо сделан для изучения тонкой структуры очень узких участков спектра.

3.9. Ширина пика, резкость, разрешающая способность

Ширина пика w (полная ширина на половине высоты, англ. FWHM) — расстояние между точками, где T = Tmax/2. По фазе: $1 + F\sin^2(\delta/2) = 2$ → $\sin(\delta/2) = 1/\sqrt F$ → полуширина $\delta = 2\arcsin(1/\sqrt F)$, полная ширина по фазе $\delta_{1/2} = 4\arcsin(1/\sqrt F)$. Один период по фазе (2π) соответствует Δλ по длине волны, поэтому

w = \Delta\lambda\,\frac{\delta_{1/2}}{2\pi},\qquad \mathcal{F} = \frac{\Delta\lambda}{w} = \frac{2\pi}{\delta_{1/2}} \approx \frac{\pi\sqrt R}{1 - R}
  • $\mathcal F$ — резкость (finesse): во сколько раз пик уже расстояния между пиками. Приближение справа получается из $\arcsin x \approx x$ при малом x (большом F); оно хорошо при R > 0,5. При R = 0,9 резкость ≈ 30.
  • Ширина существует, только если провалы ниже половины пика: $1/(1+F) < 1/2$, то есть F > 1, R > 0,172. Иначе функция theory возвращает None, и в таблице прочерк.
  • Разрешающая способность $\mathcal A = \lambda/w = m_0\mathcal F$: какую относительную разницу длин волн прибор ещё различает. При m₀ ≈ 15 800 и $\mathcal F$ ≈ 30 получается ≈ 470 000: прибор различает линии, отличающиеся на 1/470 000 длины волны (≈ 1,3 пм).

Критерий разрешения и число 0,81

Две линии одинаковой яркости, разнесённые на δλ, дают сумму двух пиков. Пока пики далеко, между ними глубокий провал. Если сблизить — провал мельчает и исчезает, два пика сливаются в один. Где граница «различимы»? Классический критерий Рэлея для дифракционной решётки: максимум одной линии попадает на первый минимум другой; тогда яркость в середине составляет 8/π² ≈ 0,81 от максимума. Для пиков Эйри нет «первого минимума», поэтому программа берёт ту же глубину провала: линии различимы, если яркость посередине не больше 0,81 максимума. Эта граница получается при δλ ≈ 1,03·w — почти ровно ширина пика.

Поиск предела — метод деления пополам (часть 4.6). dlam % fsr в verdict_text — остаток от деления: при δλ больше Δλ картина повторяется.

3.10. Сдвиг зеркала

Если увеличить зазор на λ/(2n), оптическая толщина 2nd вырастет на λ, порядок в центре m₀ — на 1. В центре «рождается» новое кольцо, а все остальные отодвигаются наружу. Считая новые кольца N при сдвиге Δd, находят длину волны: $\Delta d_N = \Delta d_0 + N\lambda/(2n)$ — прямая, наклон которой λ/(2n).

Анимация «Двигать зеркало» сдвигает Δd по кругу от 0 до наибольшего значения, кратного λ/(2n). Когда сдвиг кратен λ/(2n), картина точно такая же, как в начале, поэтому переход «конец → 0» незаметен.

3.11. Дублет и совпадение колец

Две близкие линии λ и λ + δλ дают две системы колец. При изменении d системы то расходятся, то совпадают. Кольца совпадают, когда в зазоре укладывается ровно на один порядок больше коротких волн: $2nd^* = m\lambda = (m-1)(\lambda+\delta\lambda)$, откуда $d^* = \lambda(\lambda+\delta\lambda)/(2n\,\delta\lambda) \approx \lambda^2/(2n\,\delta\lambda)$. Иначе говоря, при $d^*$ область свободной дисперсии $\Delta\lambda$ как раз равна δλ. Измерив $d^*$, находят $\delta\lambda = \lambda^2/(2nd^*)$ — это задание 6.1.

3.12. Реалистичный режим

Настоящий прибор хуже идеального по трём причинам. Программа учитывает все три.

  1. Неплоскостность зеркал h. Зеркала не идеально плоские: зазор в разных местах пучка от d − h/2 до d + h/2. Фаза в разных местах разная, от δ − a до δ + a, где $a = 2\pi n h/\lambda$ (изменение 2nd на nh даёт изменение фазы на 2π·nh/λ). Приёмник складывает свет со всей площади, то есть усредняет T по окну фаз.
  2. Ширина спектральной линии Γ. Источник светит не на одной длине волны, а в узком интервале ±Γ/2. Изменение длины волны на Δλ сдвигает фазу на 2π, поэтому ±Γ/2 дают размах фаз $\pm\pi\Gamma/\Delta\lambda$.
  3. Шум приёмника σ. Каждое показание случайно «дрожит» на доли процента.

Первые две причины независимы, поэтому их полуширины складываются как катеты: $a = \sqrt{a_1^2 + a_2^2}$ (так складываются независимые случайные разбросы). Результат — среднее функции Эйри по окну $[\delta - a, \delta + a]$:

Часть 4. Вычислительная математика программы

Как программа сама «меряет» свои графики и почему быстро рисует

4.1. Две колонки таблицы: «по графику» и «по формуле»

«По формуле» — значения из части 3, посчитанные прямо. «По графику» — программа строит кривую из десятков тысяч точек и ищет на ней пики, половину высоты и т. д., как это делал бы человек. Если обе колонки совпадают, значит и формулы, и измерения верны. Значок у плиток показывает расхождение: зелёный меньше 1 %, жёлтый меньше 5 %, красный больше.

4.2. Сколько брать точек

На ширину пика должно прийтись не меньше 30 точек, иначе пик будет измерен грубо. Но не меньше 20 000 (чтобы широкие пики тоже были гладкими) и не больше 2 000 000 (чтобы не тормозить). width or fsr — если ширины нет (R слишком мало), берём Δλ.

4.3. Поиск пика и парабола

Самая высокая точка из дискретного набора — не точный пик: настоящая вершина лежит где-то между точками. Уточнение: через три точки (левую, среднюю, правую) проводим параболу и берём её вершину.

Вывод. Пусть точки стоят на x = −1, 0, +1 (в шагах сетки) со значениями L, M, P. Парабола $y = M + bx + cx^2$: из $y(-1) = L$ и $y(1) = P$ получаем $b = (P - L)/2$, $c = (L - 2M + P)/2$. Вершина: $x^* = -b/(2c) = \frac{(L-P)/2}{L - 2M + P}$ — в коде это shift = 0.5*(left − right)/bend. Высота вершины $y^* = M + bx^*/2 = M - \frac{1}{4}(L - P)x^*$ — это mid − 0.25*(left − right)*shift. Если bend = 0 (три точки на прямой), деление запрещено через np.divide(where=…), сдвиг 0.

4.4. Ширина на половине высоты: интерполяция

  1. Найти пики, выбрать два соседних вокруг λ₁ (searchsorted даёт номер первого пика правее λ₁). np.clip(…, 1, len(pos) − 1) не даёт выйти за края списка.
  2. Δλ — разность их положений.
  3. Для ближайшего к λ₁ пика: уровень половины half = top/2. Слева от пика ищем последнюю точку ниже половины (left[-1]), справа — первую (right[0]).
  4. Между этой точкой и соседней кривая пересекает уровень; место пересечения находим линейной интерполяцией: считаем, что между двумя соседними точками кривая — прямая. np.interp(half, [T[a], T[a+1]], [x[a], x[a+1]]) отвечает на вопрос «при каком x прямая через эти две точки равна half».
  5. Контраст — высота пика, делённая на минимум кривой.

4.5. Рисование по столбцам: минимум и максимум на отрезке

Если нарисовать кривую по точкам и соединить их линиями, узкий пик может «проскочить» между точками и пропасть. Программа поступает как цифровой осциллограф: для каждого столбца пикселей находит, где кривая в этом столбце выше и ниже всего, и закрашивает полоску между ними. Тогда ни один пик не потеряется, сколько бы их ни было.

Для функции Эйри минимум и максимум на отрезке фаз [a, b] находятся без перебора. Функция периодична с периодом 2π, пики стоят на 2πm, провалы на π(2m+1). Если внутри отрезка есть число вида 2πm — максимум равен Tmax. Проверка: наибольшее кратное 2π, не превосходящее b, это floor(b/2π)·2π; если оно не меньше a — оно внутри отрезка. Аналогично для провалов со сдвигом на π. Если ни пика, ни провала внутри нет, функция на отрезке монотонна, и крайние значения — на концах.

4.6. Средняя яркость пикселя: первообразная

На картинке колец в один пиксель у края экрана могут попасть сотни тонких колец. Если взять яркость в центре пикселя, получится случайная точка на случайном кольце — картина покроется узорами (муар). Правильно — взять среднее яркости по ширине пикселя. Среднее функции на отрезке — это интеграл, делённый на длину отрезка. У функции Эйри есть первообразная:

\int\frac{d\delta}{1 + F\sin^2(\delta/2)} = \frac{2}{\sqrt{1+F}}\,\mathrm{arctg}\left(\sqrt{1+F}\;\mathrm{tg}\frac{\delta}{2}\right)

(проверяется дифференцированием). Но tg(δ/2) обращается в бесконечность при δ = π, и арктангенс «перескакивает» с +π/2 на −π/2. Поэтому фаза раскладывается на номер периода k и остаток φ ∈ [−π, π): δ = 2πk + φ. За каждый полный период интеграл набирает $2\pi/\sqrt{1+F}$ («ступенька»), а внутри периода считается по формуле (6).

  • k = floor(δ/2π + 0,5) — номер периода, в котором φ = δ − 2πk попадает в [−π, π).
  • Интеграл от d1 до d2 = (2/q)·(π(k2 − k1) + (arctg₂ − arctg₁)), где q = √(1+F). Делим на длину — получаем среднее.
  • Если отрезок почти нулевой, делить нельзя; тогда берётся просто значение в середине. np.where выбирает одно из двух для каждого элемента.

Так средняя яркость любого пикселя считается одной формулой, а не суммированием миллионов точек.

4.7. Поиск колец «по картинке»

  • Точки берутся равномерно не по радиусу, а по u = sin²θ. Фаза $\propto\sqrt{n^2 - u}$ почти линейна по u, поэтому на каждое кольцо приходится одинаковое число точек (по 6), хотя кольца к краю сгущаются.
  • periods — сколько раз фаза проходит 2π от центра до края, то есть сколько колец. Число точек — 6 на кольцо, но от 2000 до 150 000.
  • Максимумы находятся как в find_peaks, затем первые 300 уточняются «микроскопом»: 3 раза вокруг лучшей точки берутся 33 точки, шаг каждый раз в 16 раз мельче. После трёх шагов точность в 16³ = 4096 раз выше шага исходной сетки.
  • Кольца ближе к центру, чем 2 шага сетки (near), не считаются: это «пятно в центре», а не кольцо. Радиус по u: $\mathrm{tg}\,\theta = \sqrt{u/(1-u)}$, $r = f\,\mathrm{tg}\,\theta$.

4.8. Метод деления пополам (бисекция)

Задача: найти δλ, при котором провал ровно 0,81. Известно, что при малом δλ провала нет (отношение > 0,81), при большом — есть. Берём отрезок [lo, hi], смотрим середину: если там провала ещё нет, ответ правее — сдвигаем lo в середину, иначе hi. Каждый шаг вдвое сужает отрезок; 60 шагов сужают его в 2⁶⁰ ≈ 10¹⁸ раз — точнее, чем хранится число. Метод надёжен: не нужна производная, и он не может «убежать».

4.9. Логарифмическая шкала ползунка

δλ задаётся от 0,01 до 2000 пм — в 200 000 раз. На обычной шкале первое деление ползунка из 1000 было бы уже 2 пм, и малые значения не выставить. На логарифмической шкале равные шаги ползунка — это равные отношения: $\delta\lambda = lo\cdot(hi/lo)^t$, t от 0 до 1. Каждые 200 делений значение растёт в 10 раз.

4.10. «Круглые» деления осей

  1. Желаемый шаг raw = диапазон / 6.
  2. Порядок mag = 10^floor(log10(raw)): для raw = 0,037 это 0,01.
  3. Из кандидатов 1, 2, 5, 10 × mag выбирается ближайший к raw «в разах» (по модулю логарифма отношения): 0,05.
  4. Первое деление — ближайшее кратное шагу не меньше lo; дальше с этим шагом до hi.

tick_text пишет подпись с числом знаков после запятой, которое требует шаг: для шага 0,05 — два знака.

Часть 5. Погрешности, МНК и лабораторный режим

5.1. Погрешности измерений: главное

  • Любое измерение отличается от истинного значения. Случайная погрешность меняется от раза к разу (шум, неточность щелчка), систематическая — одинакова всегда (например, неправильная формула).
  • Если измерить величину N раз, лучшая оценка — среднее $\bar x = \frac1N\sum x_i$.
  • Разброс характеризует выборочное стандартное отклонение $s = \sqrt{\frac{\sum(x_i - \bar x)^2}{N-1}}$. Деление на N − 1, а не на N: одна «степень свободы» потрачена на вычисление среднего.
  • Среднее точнее одного измерения в √N раз: стандартное отклонение среднего $s/\sqrt N$.
  • Доверительная граница $\Delta = t\cdot s/\sqrt N$, где t — коэффициент Стьюдента. Он показывает, во сколько стандартных отклонений надо отступить, чтобы с вероятностью 0,95 истинное значение попало в интервал $\bar x \pm \Delta$. При малом числе измерений t большой (2 измерения — 12,7; 5 — 2,78), при большом стремится к 1,96.
  • Результат пишут как $(\bar x \pm \Delta)$ единица, погрешность — одной-двумя значащими цифрами, среднее — до того же разряда.

5.2. Метод наименьших квадратов (МНК)

Точки на графике почти ложатся на прямую, но не точно. Какая прямая «лучше всех»? Та, у которой сумма квадратов вертикальных отклонений точек от неё наименьшая. Это и есть МНК.

Ищем прямую y = a + bx, минимизирующую $S(a,b) = \sum(y_i - a - bx_i)^2$. В минимуме производные по a и b равны нулю; решение этих двух уравнений:

b = \frac{\sum(x_i-\bar x)(y_i - \bar y)}{\sum(x_i - \bar x)^2},\qquad a = \bar y - b\bar x

Разброс точек вокруг прямой: $s^2 = \frac{\sum(y_i - a - bx_i)^2}{n-2}$ (две степени свободы потрачены на a и b). Отсюда стандартные отклонения коэффициентов:

\sigma_b = \frac{s}{\sqrt{\sum(x_i-\bar x)^2}},\qquad \sigma_a = s\sqrt{\frac1n + \frac{\bar x^2}{\sum(x_i-\bar x)^2}}

Доверительные границы $\Delta b = t\sigma_b$, $\Delta a = t\sigma_a$ с t для n − 2 степеней свободы.

Прямая через начало координат y = bx (когда теория говорит, что a = 0): $b = \sum x_iy_i/\sum x_i^2$, $s^2 = \sum(y_i - bx_i)^2/(n-1)$, $\sigma_b = s/\sqrt{\sum x_i^2}$.

Функция возвращает словарь, чтобы вызывающий код брал нужное по имени: fit["b"], fit["db"]. float("nan") — «не число» там, где погрешность не определена (две точки для прямой общего вида: 0 степеней свободы).

5.4. Перенос погрешностей

Если y = f(x), то $\Delta y \approx |f'(x)|\,\Delta x$. Частные случаи из программы:

  • $\lambda = \sqrt{2nb\cdot10^{-15}}$ ~ √b: относительная погрешность вдвое меньше: $\Delta\lambda/\lambda = \Delta b/(2b)$ → lam * db / (2 * b).
  • λ ~ b: $\Delta\lambda/\lambda = \Delta b/b$ → lam * db / b.
  • Произведение и частное независимых величин: относительные погрешности складываются квадратично. Для $\delta\lambda = \lambda^2/(2nd^*)$: $\varepsilon = \sqrt{(2\Delta\lambda/\lambda)^2 + (\Delta d^*/d^*)^2}$ → math.hypot(2 * dlam_err / lam, e / m). Двойка — потому что λ в квадрате.

5.5. Варианты: откуда берутся скрытые значения

Компьютер не умеет выдавать по-настоящему случайные числа — он считает их по формуле из начального числа, «зерна» (seed). Одно и то же зерно — одна и та же последовательность. Поэтому вариант 7 даёт одни и те же λ, δλ, A на любом компьютере, в любой день, и преподаватель может заранее посчитать ответы.

  • random.Random("fabry-perot-variant-7") — свой генератор с зерном-строкой. Строка превращается в число одинаково на всех системах (в отличие от встроенной функции hash, которая для строк меняется от запуска к запуску). Свой генератор не зависит от остальной программы: сколько бы раз кто-то ни вызывал random в другом месте, варианты не изменятся.
  • round(rng.uniform(450.0, 690.0), 1) — случайная длина волны с шагом 0,1 нм.
  • rng.choice([...]) — случайный элемент списка; rng.shuffle(options) — перемешивание.
  • Для задания с кольцами перебираются пары (d, f) в случайном порядке, пока на экране радиусом 10 мм не окажется хотя бы 7 колец. Цикл for … break: после break переменные d, f хранят найденную пару.

5.6. Серии и журнал

Каждое задание — объект Series. Поле kind говорит, как записывается точка:

  • pair — два правых щелчка по графику T(λ): y = |x₂ − x₁|. Первый щелчок запоминается в journal.pending, второй даёт точку. x — функция текущего параметра (xfunc(ctx[xkey]), например 1/d).
  • ring — щелчок по кольцу: y = r², x — номер кольца по порядку.
  • param — кнопка «Записать»: запоминается текущее значение параметра (source).
  • point — просто показание курсора.

Точка хранится словарём {"x", "y", "note", "ctx"}, где ctx — параметры окна в момент записи (n, d, f, R). Все серии — словарь списков self.data. Он превращается в текст JSON (json.dumps) и сохраняется в настройках после каждого изменения; при запуске читается обратно (load_json) с проверкой, что каждая запись — словарь с x и y (защита от испорченного файла).

known_lambda выбирает среди серий 2, 4, 5 ту, где λ получилась с наименьшей относительной погрешностью, и использует её в заданиях 6 и 7.

Задание 7 (поглощение): из $T_{\max} = (1-R-A)^2/(1-R)^2$ следует $\sqrt{T_{\max}} = 1 - A/(1-R)$, $A = (1-R)(1-\sqrt{T_{\max}})$.

Часть 6. Qt: как устроено окно

Библиотека окон, кнопок и рисования

6.1. Qt, PyQt5 и PyQt6

Qt (читается «кьют») — большая библиотека на языке C++ для программ с окнами. Она одна и та же на Windows, macOS и Linux: программа пишется один раз. PyQt — «переходник», через который Qt вызывается из Python. Есть две версии: PyQt5 (для Qt 5) и PyQt6 (для Qt 6). Qt 6 работает только на Windows 10 и новее, поэтому для Windows 7/8/8.1 нужен PyQt5. Различия между ними мелкие, и все они собраны в qt.py:

  • В Qt 6 перечисления (наборы констант) пишутся полностью: Qt.AlignmentFlag.AlignCenter. В PyQt5 такая запись тоже работает (начиная с 5.11), поэтому в программе везде полная форма — она подходит обоим.
  • QAction в Qt 6 переехал в модуль QtGui.
  • Положение мыши в событии: event.position() в Qt 6, event.localPos() в Qt 5.
  • Остальные модули пишут from .qt import … и не знают, какая версия подключена.

Три главных модуля Qt: QtCore — основа без графики (таймеры, сигналы, настройки, точки и прямоугольники); QtGui — рисование (цвета, шрифты, картинки, художник QPainter); QtWidgets — элементы окна (кнопки, поля, таблицы).

6.2. Приложение и цикл событий

Программа с окном не выполняется «сверху вниз до конца». После создания окна она входит в цикл событий: бесконечно ждёт, что что-то произойдёт (щелчок, нажатие клавиши, сработал таймер, окну нужно перерисоваться), и вызывает нужную функцию. Потом снова ждёт. Цикл заканчивается, когда закрыли последнее окно.

  • QApplication — объект «программа целиком». Он один на программу и должен быть создан раньше любого виджета.
  • app.exec() в main() — запуск цикла событий. Отсюда управление не вернётся, пока программа работает.
  • Отсюда важное правило: функция, вызванная из цикла, должна быстро закончиться. Пока она работает, окно не перерисовывается и не реагирует на мышь («зависает»). Поэтому пересчёт сделан быстрым (10 мс), а анимация идёт через таймер, а не через цикл с sleep.
  • setStyle("Fusion") — встроенный в Qt стиль, одинаковый на всех системах; без него кнопки выглядели бы по-разному на Windows и macOS, и наша таблица стилей ложилась бы на них по-разному.
  • font.setFamilies(FONTS) — список шрифтов по порядку предпочтения: Segoe UI есть на Windows, SF Pro на macOS, Ubuntu/Cantarell/Noto на Linux. Qt берёт первый найденный.
  • QLocale — «местные правила»: русская локаль делает десятичную запятую в полях ввода.
  • Настройки HiDPI — в части 6.10.

6.4. Компоновки (layouts)

Виджеты не расставляются по координатам вручную. Их кладут в компоновку, и она сама расставляет и растягивает их при изменении размера окна.

  • QVBoxLayout — друг под другом; QHBoxLayout — в строку.
  • QGridLayout — сетка: grid.addWidget(w, строка, столбец). Каждый параметр занимает две строки сетки (сверху название и пределы, снизу ползунок и поле). setColumnStretch(0, 1) — первый столбец забирает всё лишнее место.
  • QFormLayout — «подпись: поле» в две колонки (окно лабораторной).
  • addWidget(w, 1) — второй аргумент stretch: доля лишнего места. addStretch() — пустая «пружина», которая отталкивает остальное.
  • setContentsMargins(лево, верх, право, низ) — поля; setSpacing — промежуток между элементами.
  • Политика размера (QSizePolicy): насколько виджет согласен сжиматься и растягиваться. У подзаголовка в шапке стоит Ignored: его желаемая ширина не учитывается, и на узком экране он обрезается, а не раздвигает окно.
  • Компоновки вкладываются: layout.addLayout(другая).

6.5. Сигналы и слоты

Виджеты сообщают о событиях сигналами: «меня нажали», «моё значение изменилось». К сигналу можно подключить любую функцию (её называют слотом). Когда сигнал испускается, Qt вызывает все подключённые функции. Кнопка не знает, что делает окно, а окно не опрашивает кнопку — они связаны только подключением.

button.clicked.connect(self.save_png)              # щелчок → сохранить снимок
self.slider.valueChanged.connect(self.slider_moved)  # новое положение → функция получит число
self.ring_view.hovered.connect(self.plot_r.set_hover)  # сигнал одного виджета → метод другого

Стандартные сигналы, которые использует программа: clicked (кнопка), toggled(bool) (переключатель), valueChanged (ползунок, поле), currentIndexChanged (список), timeout (таймер), accepted/rejected (кнопки диалога), sectionResized (ширина столбца таблицы).

Свои сигналы

class Plot(QtWidgets.QWidget):
    hovered = Signal(object)          # объявление: сигнал с одним значением любого типа
    picked = Signal(float, float)     # сигнал с двумя дробными числами
    ...
        self.picked.emit(x, y)        # испустить: все подключённые функции получат (x, y)

Сигнал объявляется как атрибут класса (Signal — это pyqtSignal), а испускается методом emit. object нужен для hovered, потому что передаётся либо число, либо None (мышь ушла).

Связь курсоров

Разрез колец и картина колец подключены друг к другу «крест-накрест»: наведение на кольца испускает hovered(радиус), разрез ставит свой пунктир на тот же радиус — и наоборот. Зацикливания нет, потому что set_hover не испускает сигнал обратно.

blockSignals

Ползунок и поле связаны в обе стороны: сдвинул ползунок — поле обновилось; ввёл число — ползунок сдвинулся. Без защиты получилось бы эхо: поле меняет ползунок, ползунок шлёт сигнал и снова меняет поле (с округлением до 1/1000 шкалы!). slider.blockSignals(True) временно «глушит» сигналы ползунка на время программной установки.

6.7. Таймеры

  • QTimer испускает сигнал timeout через заданный интервал (мс). Обычный — повторяется, setSingleShot(True) — один раз. start(), stop(), isActive().
  • QTimer.singleShot(1500, функция) — вызвать функцию один раз через 1,5 с (самопроверка).
  • QElapsedTimer — секундомер: start(), потом elapsed() — сколько миллисекунд прошло.

В окне три таймера:

  1. timer (одноразовый, 15 мс) → recalc. Ползунок при движении шлёт десятки сигналов; schedule() запускает таймер, только если он не запущен. Все сигналы за 15 мс сливаются в один пересчёт.
  2. tween_timer (16 мс, ≈ 60 кадров в секунду) → tween_step, плавные переходы.
  3. scan_timer (30 мс) → scan_step, анимация зеркала.

Таймер срабатывает внутри цикла событий, поэтому между кадрами окно успевает обработать мышь и перерисоваться.

6.10. Чёткость на экранах с масштабом (HiDPI)

На экране ноутбука с масштабом 150 % одна «точка» интерфейса — это 1,5 физических пикселя; на Retina (Mac) — 2 пикселя. Если нарисовать картинку по точкам, а экран растянет её в 1,5 раза, она станет мыльной.

  • Размеры виджетов в Qt — в логических точках. devicePixelRatioF() — сколько физических пикселей в точке (1; 1,25; 1,5; 2).
  • Поэтому все свои картинки программа создаёт в физических пикселях (ширина × ratio) и сообщает Qt image.setDevicePixelRatio(ratio): «эта картинка плотная, рисуй её в ratio раз мельче». Получается чёткость пиксель в пиксель.
  • В Qt 5 это включается вручную атрибутами AA_EnableHighDpiScaling и AA_UseHighDpiPixmaps до создания приложения; в Qt 6 включено всегда.
  • HighDpiScaleFactorRoundingPolicy.PassThrough — не округлять 1,25 до 1 или 1,5 до 2, а использовать точный масштаб. Иначе на 125 % всё было бы либо мелким, либо огромным.

Часть 7. Визуал: цвета, темы, рисование

7.1. Как задаётся цвет

  • RGB — три числа 0…255: сколько красного, зелёного, синего. Экран смешивает их: (255, 255, 0) — жёлтый.
  • Шестнадцатеричная запись #35D0BA: по две цифры на канал в системе счисления по основанию 16 (0…9, A…F). 35₁₆ = 53, D0₁₆ = 208, BA₁₆ = 186.
  • Альфа — непрозрачность 0…255: 0 — невидимый, 255 — сплошной. THEME.color("surface", 235) — цвет карточки, чуть прозрачный.
  • HSL — другой способ: оттенок (hue, «какой цвет радуги»), насыщенность (saturation, «насколько не серый»), светлота (lightness). Удобен, когда нужно сделать тот же оттенок светлее или темнее.
  • QColor — объект цвета Qt; понимает все эти записи: QColor("#35D0BA"), QColor.fromRgbF(r, g, b) (доли 0…1), QColor.fromHslF(h, s, l); .name() — обратно в «#rrggbb».
  • Premultiplied («предумноженный»): каналы цвета заранее умножены на альфу. Полупрозрачный белый хранится как (128, 128, 128, 128), а не (255, 255, 255, 128). Так Qt накладывает картинки быстрее: не надо умножать при каждом рисовании.

7.2. Две темы

Все цвета собраны в словари DARK и LIGHT в theme.py с одинаковыми ключами: bg (фон окна), surface (карточки), raised (поля), text, muted (второстепенный текст), accent (бирюзовый) и т. д. Тройки ok/bad/warn/info — фон, текст и рамка цветных подложек. Смена темы (toggle_theme):

  1. THEME.set("light") — подменить словарь;
  2. apply_theme: новая палитра Qt, новая таблица стилей, перекрасить радужный ползунок и значки примеров, заново «отполировать» подложки;
  3. recalc() — перерисовать графики: цвета кривых зависят от фона.

Таблица стилей собирается f-строкой с цветами текущей темы. Фигурные скобки самого QSS в f-строке удваиваются ({{ и }}), иначе Python принял бы их за вставку значения.

Смена вида на лету: polish

Qt применяет стиль, когда виджет создаётся. Если потом поменять свойство kind, Qt сам этого не заметит. unpolish/polish заставляет пересчитать стиль. Так подложка вывода становится зелёной или красной. Чтобы не делать это лишний раз, программа сначала проверяет, изменился ли kind.

Палитра

qt_palette() — цвета для стандартных окон, которые таблица стилей не покрывает: «Сохранить как…», сообщения, подсказки. QPalette.ColorRole — роли: Window (фон), Text, Highlight (выделение) и т. д.

7.4. Цвет длины волны

Точного перевода «длина волны → RGB» не бывает: монитор не может показать чистые спектральные цвета. Схема Брутона — простое кусочно-линейное приближение: по отрезкам спектра один канал растёт или падает линейно. У краёв спектра (глаз там видит хуже) цвет притемняется множителем k.

line_color делает из этого цвет кривой, читаемый на фоне темы: переводит в HSL, на тёмном фоне поднимает светлоту не ниже 0,62 (фиолетовый иначе не виден на чёрном), на светлом — опускает (жёлтый на белом особенно, поэтому yellowish — «насколько оттенок близок к жёлтому»). spectrum_gradient собирает 21 точку радуги в градиент для дорожки ползунка λ.

7.5. QPainter — художник

Всё своё рисование делается объектом QPainter: «художник» рисует на «холсте» — виджете, картинке QImage или QPixmap.

p = QPainter(self)                                  # рисовать на этом виджете
p.setRenderHint(QPainter.RenderHint.Antialiasing)   # сглаживание краёв
p.setPen(QPen(QColor("#FFA54A"), 1.6))              # перо: цвет и толщина линий и текста
p.setBrush(QColor("#111923"))                       # кисть: чем заливать фигуры
p.drawLine(QPointF(0, 0), QPointF(100, 50))
p.drawRoundedRect(QRectF(10, 10, 200, 100), 14, 14) # прямоугольник со скруглением 14
p.drawEllipse(QPointF(50, 50), 4.5, 4.5)            # круг: центр и два радиуса
p.drawText(QRectF(...), Qt.AlignmentFlag.AlignCenter, "текст")
p.drawImage(QPointF(x, y), image)
p.end()                                             # закончить (для QImage обязательно)
  • Система координат: начало в левом верхнем углу, x вправо, y вниз. Поэтому в to_y большее значение даёт меньший y: area.bottom() − ….
  • QPointF, QRectF — точка и прямоугольник с дробными координатами (F — float). rect.adjusted(0.5, 0.5, −0.5, −0.5) — прямоугольник, сжатый на полпикселя: линия толщиной 1 по центру пикселя получается чёткой.
  • Qt.PenStyle.NoPen — без контура; Qt.BrushStyle.NoBrush — без заливки; pen.setStyle(Qt.PenStyle.DashLine) — пунктир.
  • p.fontMetrics().horizontalAdvance(текст) — ширина текста в точках текущим шрифтом; .height() — высота строки. Нужны, чтобы подложка была по размеру надписи (pill).
  • p.save() / p.translate(x, y) / p.rotate(−90) / p.restore() — запомнить состояние, сдвинуть начало координат, повернуть, вернуть как было. Так пишется вертикальная подпись оси Y.
  • pixel_font(widget, px, bold) — шрифт заданного размера в точках экрана (а не в пунктах), чтобы графики выглядели одинаково на всех системах.

7.6. График: координаты, масштаб, кэш

  • area() — поле графика внутри виджета: отступ 64 точки слева и сверху (подписи и заголовок), 22 справа, 50 снизу.
  • to_x(area, x) — перевод значения в точку экрана: доля пути от x0 до x1, умноженная на ширину поля. to_y — то же по вертикали, перевёрнутое.
  • Масштаб хранится как zoom = (a, b) — доли всей ширины графика, от 0 до 1. view() переводит их в значения x. Колёсико (wheelEvent) умножает ширину видимой части на 0,8 за щелчок, и точка под курсором остаётся на месте: center = a + at·(b − a), новое a = center − at·span. Перетаскивание сдвигает (a, b), не давая выйти за 0 и 1.
  • Кэш. Рисование сетки, подписей и кривых занимает несколько миллисекунд, а мышь двигается 60–120 раз в секунду. Поэтому готовый рисунок хранится в QPixmap self.base. paintEvent: если base нет — нарисовать его (draw_base); потом скопировать его на экран и сверху нарисовать только перекрестие (draw_overlay). При новых данных, масштабе или размере base = None.

7.7. Растеризатор кривой

Растеризация — превращение фигуры в пиксели. Вместо «нарисуй линию через тысячу точек» программа сама решает для каждого пикселя поля графика, насколько он закрашен — сразу для всех пикселей через numpy.

  1. Для каждого из width столбцов пикселей curve.span даёт наименьшее и наибольшее значение кривой (часть 4.5). Переводим в строки пикселей: top и bottom.
  2. Линия. Пиксель строки row занимает по вертикали [row, row + 1]. Полоска кривой — [top − half, bottom + half], half ≈ 0,95 пикселя (толщина ~1,9). Доля пикселя внутри полоски — длина пересечения двух отрезков: min(row + 1, bottom + half) − max(row, top − half), обрезанная в [0, 1]. Пиксель, закрытый наполовину, получает прозрачность 0,5 — край линии гладкий (сглаживание).
  1. Заливка под кривой: доля пикселя ниже верха кривой, умноженная на прозрачность, которая тает книзу (fade от 0,36 до 0,03).
  2. Свечение (в тёмной теме): расстояние от пикселя до полоски, делённое на 3,2 пикселя; чем ближе, тем ярче; glow *= glow — квадрат делает спад мягче.
  3. Сложение слоёв: как наложенные цветные плёнки. Плёнка с непрозрачностью a пропускает долю 1 − a; несколько плёнок пропускают произведение (1 − a)(1 − b)(1 − c). Итоговая непрозрачность 1 − это произведение. Так слои не дают «больше 100 %».
  4. Цвет у всей кривой один, поэтому пиксель — это только число 0…255 (прозрачность). Таблица color_table(color) из 256 готовых цветов «этот цвет с прозрачностью k» переводит всю картинку в цвета одной операцией table[alpha].
  5. Массив чисел uint32 превращается в картинку Qt: QImage(байты, ширина, высота, байт_в_строке, формат). Байт в строке — 4 × ширина (по 4 байта на пиксель).

Шум (реалистичный режим): верх и низ полоски в каждом столбце смещаются на случайную величину. Генератор создаётся с зерном self.seed, которое меняется только при пересчёте. Поэтому при движении мыши (перерисовке без пересчёта) шум не «кипит», а стоит на месте.

(alpha * k + 127) // 255 — умножение цвета на прозрачность с округлением (premultiplied, часть 7.1); // — деление нацело.

7.8. Картина колец

  1. Цвет зависит только от расстояния до центра. Поэтому вместо полумиллиона вычислений для пикселей считается одна короткая таблица цветов по расстоянию с шагом ¼ пикселя (несколько тысяч значений), а затем каждый пиксель берёт цвет из неё.
  2. Карта номеров index — для каждого пикселя номер строки таблицы (4 × расстояние / размер пикселя). Она зависит только от размера картинки и положения лупы, поэтому хранится (self.index, словарь с ключом (сторона, увеличение, центр)) и не пересчитывается, пока их не изменят.
  3. Яркость для каждого расстояния — среднее функции Эйри по ширине пикселя через первообразную (часть 4.6): airy_mean(p1 + blur, p2 − blur, …). Фаза убывает с радиусом, поэтому p1 > p2, и отрезок от p1 + blur до p2 − blur — это окно пикселя, расширенное размытием на blur с каждой стороны (порядок концов среднему не важен).
  4. Свечение — к яркости добавляется её размытая копия: свёртка (np.convolve) с гауссовым ядром — весами $e^{-x^2/2\sigma^2}$, нормированными на сумму 1. Каждая точка становится взвешенным средним соседей: так выглядит ореол на фотографии.
  5. Гамма. Монитор показывает яркость не пропорционально числу: значение 128 из 255 выглядит не вдвое темнее 255, а примерно в 4,6 раза (яркость ∝ значение^2,2). Чтобы физическая яркость 0,1 выглядела как 0,1, значение возводится в степень 1/2,2. Без этого тусклые кольца слились бы с чёрным фоном.
  6. Цвет каждой линии — wavelength_rgb; при двух линиях их вклады складываются.
  7. Край экрана: прозрачность плавно спадает от 1 до 0 на последнем пикселе круга — край гладкий.
  8. Числа собираются в 32-битные цвета сдвигами, таблица «раскладывается» по картинке: table[index]. .copy() в конце — QImage, созданный из байтов, не владеет ими; копия делает свою память, иначе картинка испортилась бы, когда Python освободит временный массив.

Лупа

scale — увеличение (1…40), center — какая точка экрана прибора (в метрах от центра колец) стоит в середине вида. Размер точки виджета в метрах pixel = 2·half/(size·scale). При повороте колёсика точка под курсором остаётся на месте: center_new = x − (x − center)·(scale_old/scale_new).

Оправа окуляра и подписи

decorate один раз рисует прямо на картинке ободок и 72 деления через 5° (каждое шестое — длинное, через 30°). Координаты делений — через cos и sin угла. paintEvent поверх картинки рисует подпись, масштабную линейку «круглой» длины (через ticks) и пунктирную окружность под курсором со значениями r, m, I.

Часть 8. Анимация, путь данных и скорость

8.1. Кадры и время

Анимация — это быстрая смена кадров. 60 кадров в секунду — кадр каждые ≈ 16,7 мс. Есть два способа двигать картинку:

  • по кадрам: каждый кадр прибавлять фиксированный шаг. На медленном компьютере кадров меньше, и анимация идёт медленнее;
  • по времени: каждый кадр смотреть на секундомер и ставить значение, какое должно быть в этот момент. На медленном компьютере кадров меньше, но переход длится те же 0,85 с. Программа использует этот способ.

8.2. Плавный переход (tween)

Слово tween — от in-between, «промежуточные кадры». Переход описывается пятью числами: откуда, куда, когда начался, по логарифму ли, длительность. Они хранятся в self.tweens[ключ].

  1. t = (сейчас − начало)/длительность — доля пройденного времени, от 0 до 1.
  2. e = ease(t) — доля пройденного пути (см. ниже).
  3. Значение: a + (b − a)·e. Для δλ, у которого логарифмическая шкала, путь проходится «по отношениям»: a·(b/a)^e. От 1 пм до 1000 пм на середине пути будет 31,6 пм, а не 500 — движение выглядит равномерным.
  4. Когда t дошло до 1, ставится точное конечное значение и переход удаляется. Нет переходов — таймер останавливается.
  5. В конце — recalc(): картинка по новым промежуточным значениям.

list(self.tweens.items()) — копия, потому что внутри цикла из словаря удаляются элементы, а менять словарь, по которому идёт цикл, нельзя.

Кривая разгона и торможения

При равномерном движении (e = t) картинка резко трогается и резко встаёт — это выглядит механически. Кубическая кривая ease-in-out: первая половина — $4t^3$ (медленный старт, ускорение), вторая — зеркальная $1 - (2-2t)^3/2$ (торможение). В точке t = 0,5 обе дают 0,5, и скорости совпадают — стык незаметен. Скорость в начале и в конце нулевая.

8.3. Откуда пришло значение: ползунок, ввод или стрелка

Задача: ползунок меняет картину сразу, введённое число — плавно (0,85 с), шаг стрелкой или колёсиком — коротким переходом (0,15 с), готовый пример — плавно. Всё это приходит одним сигналом valueChanged поля. Различаются флажками:

  • from_slider — ставит slider_moved на время установки значения в поле → «сразу».
  • forced — ставит программа в set(value, smooth) (примеры, восстановление) → как велено.
  • spin.stepping — ставит StepSpin.stepBy (стрелки и колёсико) → «быстро».
  • ничего из этого → число ввели с клавиатуры → плавно.

setKeyboardTracking(False): поле присылает значение только после Enter или ухода из поля, а не после каждой цифры. Иначе при вводе «12» картина поплыла бы сначала к 1, потом к 12.

8.4. Изменение параметра

  • self.shown — значения, которые сейчас на картинке; params[key].value() — что в поле. Во время перехода они отличаются.
  • Переход начинается с того, что сейчас на картинке. Если ввести новое число, пока идёт старый переход, картинка не прыгнет — новый переход подхватит движение с текущего места.
  • Если параметр меняли руками (не пример), подсветка кнопки примера снимается.

8.5. Анимация зеркала

Каждые 30 мс Δd растёт на λ/(2n)/56: одно новое кольцо за 56 кадров ≈ 1,7 с. При переходе за seamless_shift значение начинается заново без скачка (часть 3.10). display показывает значение в поле и на ползунке, заглушив сигналы, — иначе поле сообщило бы об изменении и запустило бы ещё и переход.

8.6. Путь данных: от ползунка до картинки

Главная функция — recalc. По шагам:

  1. effective() — значения для физики: видимые, а в лабораторной вместо λ и A — скрытые из варианта.
  2. Перевод в СИ: нм → м (* 1e-9), мм → м; d = d + Δd. Поглощение ограничивается: A ≤ 1 − R.
  3. theory(…) — всё «по формуле». realism и blur_halfwidth — размытие и шум.
  4. График T(λ): десятки тысяч точек вокруг λ₁ (±1,5 Δλ), измерения measure_curve, затем show_transmission отдаёт графику кривую-формулу, метки λ₁, λ₂ и отрезки Δλ, w.
  5. Картина колец: ring_view.show_data — сама картинка посчитается при рисовании.
  6. Радиусы колец «по картинке» (measure_rings) и «по формуле» (ring_radii).
  7. Разрез колец: кривые-формулы для каждой линии (две линии делят свет пополам) и кривая суммы.
  8. Таблица и плитки (fill_table), вывод о разрешении (verdict_text).

Виджеты при этом ничего не рисуют сразу: show_data только запоминает данные и вызывает update(). Рисование произойдёт, когда Qt вызовет paintEvent.

9.2. CSV для Excel

CSV (comma-separated values) — таблица в виде текста: строки файла — строки таблицы, значения разделены разделителем. Русский Excel ожидает разделитель «;» (потому что запятая занята под десятичную дробь) и десятичную запятую. Поэтому csv.writer(file, delimiter=";"), числа через fmt.plain (запятая, 6 значащих цифр) и кодировка utf-8-sig (часть 1.8). writerow([]) — пустая строка между разделами. Точек графика может быть до 2 миллионов, поэтому пишется каждая step-я, не больше ≈ 20 000 строк: x[::step] — срез с шагом.

В лабораторной сохраняется только журнал и видимые параметры (write_lab_csv), иначе в файле оказалась бы скрытая длина волны.

9.3. Буфер обмена

QApplication.clipboard().setText(текст). Столбцы разделены табуляцией \t, строки — переводом строки \n. Excel и Word при вставке такого текста сами делают таблицу.

Часть 10. Автоматические проверки

10.1. Зачем тесты

Тест — маленькая программа, которая запускает кусок основной программы и проверяет результат. После любого изменения достаточно одной команды, чтобы узнать, не сломалось ли что-то. Все 29 тестов проходят за несколько секунд; GitHub запускает их перед каждой сборкой, и сломанная программа не соберётся.

10.2. pytest

pytest — библиотека для тестов. Она находит в папке tests файлы test_*.py, в них — функции test_*, выполняет каждую и сообщает, какие упали.

python -m pytest tests             # все тесты
python -m pytest tests -v          # с именем каждого теста
python -m pytest tests -k rings    # только тесты, в имени которых есть «rings»
python -m pytest tests -x          # остановиться на первой ошибке
  • assert условие — команда Python: если условие ложно, возникает ошибка. pytest показывает, какие значения были слева и справа.
  • pytest.approx — сравнение дробных чисел с допуском: got == pytest.approx(expect, rel=1e-3) — отличие не больше 0,1 %.
  • np.allclose(a, b, rtol, atol) — то же для массивов numpy.
  • @pytest.mark.parametrize("R", [0.3, 0.7, 0.9, 0.98]) — запустить тест четыре раза с разными R.
  • pytest.importorskip("numpy") — если библиотеки нет, тест пропускается, а не падает.

10.3. Фикстура: окно для тестов

@pytest.fixture(scope="module")
def window(tmp_path_factory):
    home = tmp_path_factory.mktemp("settings")
    QtCore.QSettings.setPath(QtCore.QSettings.Format.IniFormat,
                             QtCore.QSettings.Scope.UserScope, str(home))
    ...
    win = MainWindow()
    win.show()
    yield win                 # тесты получают окно
    win.close()               # после всех тестов модуля — закрыть
  • Фикстура — функция, которая готовит то, что нужно тестам. Тест просит её, называя аргумент тем же именем: def test_slider_is_instant(window).
  • scope="module" — окно создаётся один раз на весь файл, а не для каждого теста.
  • yield — «отдать значение и подождать»: код после него выполнится, когда тесты закончатся.
  • tmp_path_factory.mktemp — временная папка; QSettings.setPath направляет настройки туда. Тесты не видят и не портят настройки настоящей программы, и каждый запуск начинается с чистого листа.
  • Переменная QT_QPA_PLATFORM=offscreen (ставится в начале файла через os.environ.setdefault) — Qt рисует окна в памяти. Так тесты идут на сервере без монитора.
def wait(ms):
    loop = QtCore.QEventLoop()
    QtCore.QTimer.singleShot(ms, loop.quit)
    loop.exec()

Как подождать, чтобы при этом работали таймеры окна (плавный переход)? time.sleep не подходит: он остановил бы всё. Функция запускает маленький цикл событий и выходит из него через ms миллисекунд — за это время таймеры окна успевают сработать.

Часть 11. Упаковка: из кода — программа

Как получаются файлы, которые запускаются двойным щелчком без установленного Python

11.1. Задача

Чтобы запустить run.py, нужны Python нужной версии, numpy, PyQt и сама библиотека Qt (десятки мегабайт файлов на C++). У студента на компьютере в аудитории этого нет. Упаковка — сложить всё это в один файл или одну папку, которая запускается сама.

11.2. PyInstaller

PyInstaller читает run.py, находит все импорты (и импорты импортов), копирует сам Python, все нужные модули и библиотеки в одно место и добавляет маленькую программу-«загрузчик» (bootloader), которая при запуске поднимает этот встроенный Python и выполняет run.py.

В Windows 7 её приносит обновление KB2999226, которое на компьютерах в аудиториях часто не установлено. Сборка находит эти файлы в Windows SDK на сборочном компьютере (папка Windows Kits\10\Redist\…\ucrt\DLLs\x86) и кладёт внутрь exe ключом --add-binary. Кусок сборки на PowerShell:

$ucrt = Get-ChildItem "${env:ProgramFiles(x86)}\Windows Kits\10\Redist" -Recurse -Directory |
        Where-Object { $_.FullName -match 'ucrt\\DLLs\\x86$' } | Select-Object -First 1
  • PowerShell — командная оболочка Windows. Переменные начинаются с $.
  • Get-ChildItem … -Recurse -Directory — все папки внутри, на любой глубине.
  • | — «передать результат следующей команде» (конвейер).
  • Where-Object { … -match '…' } — оставить те, чей путь подходит под регулярное выражение (\\ — обратная косая, $ — конец строки).
  • Select-Object -First 1 — первую найденную.
  • @('a', 'b') — список; pyinstaller @common — подставить все элементы списка как аргументы.

Сведения о версии

packaging/windows/version.txt — описание в формате PyInstaller (это код Python, который PyInstaller выполняет): версия 2.0.0, название, организация. 041904B0 и [0x0419, 1200] — код языка (0x0419 — русский) и кодовой страницы (1200 = Unicode). 11.4. macOS

Что такое .app

Программа на Mac — это папка с окончанием .app, которую Finder показывает как один значок:

Fabry-Perot.app/
  Contents/
    Info.plist          сведения о программе: имя, версия, значок, минимальная версия macOS
    MacOS/Fabry-Perot   сама программа (загрузчик PyInstaller)
    Resources/          значок .icns

Info.plist — файл в формате XML со списком «ключ — значение». PlistBuddy — встроенная в macOS программа для его правки: Add :CFBundleDisplayName string 'Фабри — Перо' добавляет русское имя, Set :CFBundleShortVersionString 2.0.0 — версию, LSMinimumSystemVersion 11.0 — «не ниже macOS 11». || true в конце команды оболочки — «если команда не удалась (ключ уже есть), не считать это ошибкой».

Две сборки: Apple Silicon и Intel

Маки бывают на процессорах Apple (M1–M4, архитектура arm64) и на Intel (x86_64). Это разные системы команд процессора, поэтому программа собирается дважды на двух разных сборочных компьютерах: macos-14 (Apple Silicon) и macos-15-intel. Переменная MACOSX_DEPLOYMENT_TARGET=11.0 говорит компилятору «делай совместимо с macOS 11». numpy закреплён на 1.26.4: его готовые сборки работают с macOS 11, а у более новых — только с macOS 14.

Подпись и Gatekeeper

На Apple Silicon программа обязана быть подписана, хотя бы «ad-hoc» (без сертификата разработчика): codesign --force --deep --sign - Fabry-Perot.app. Дефис вместо имени сертификата — и есть ad-hoc; --deep — подписать и все библиотеки внутри. Gatekeeper (защита macOS) всё равно предупредит о программе из интернета от неизвестного разработчика: поэтому первый запуск — правый щелчок → «Открыть». Если macOS пишет «повреждена», команда xattr -cr Fabry-Perot.app снимает с файлов метку «скачано из интернета» (расширенный атрибут com.apple.quarantine).

11.5. Linux

  • glibc. Почти все программы Linux используют системную библиотеку C (glibc). Программа, собранная на системе с новой glibc, не запустится на старой, а наоборот — запустится. Поэтому сборка делается на Ubuntu 22.04 (glibc 2.35): она работает на Ubuntu 22.04 и новее, Debian 12, Fedora 36+.
  • xcb. Окна в Linux рисует графический сервер X11 (или Wayland с совместимостью с X11). Qt общается с ним через библиотеки libxcb-*. На сборочном компьютере они ставятся через sudo apt-get install (apt — установщик пакетов Ubuntu, sudo — от имени администратора), и PyInstaller кладёт их внутрь файла — на компьютере пользователя их может не быть.
  • Ярлык в меню — файл .desktop: название (в том числе по-русски, Name[ru]), команда запуска Exec, значок Icon, категория меню.

install.sh построчно

#!/bin/sh                                    # «выполнять этот файл программой /bin/sh»
set -e                                       # остановиться на первой ошибке
HERE="$(cd "$(dirname "$0")" && pwd)"         # папка, где лежит сам скрипт
BIN="$HOME/.local/bin"                       # личные папки пользователя — sudo не нужен
APPS="$HOME/.local/share/applications"       # сюда кладутся ярлыки меню
ICONS="$HOME/.local/share/icons/hicolor/256x256/apps"
if [ "$1" = "--remove" ]; then ... fi        # ./install.sh --remove — удалить
mkdir -p "$BIN" "$APPS" "$ICONS"             # создать папки (-p — вместе с родительскими, без ошибки, если есть)
cp "$HERE/FabryPerot" "$BIN/FabryPerot"      # скопировать программу
chmod +x "$BIN/FabryPerot"                   # разрешить запуск (x — execute)
sed "s|^Exec=.*|Exec=$BIN/FabryPerot|" … > … # подставить в ярлык полный путь к программе
update-desktop-database "$APPS" 2>/dev/null || true   # обновить меню; ошибки не показывать

$0 — путь к самому скрипту, $1 — первый аргумент, $HOME — домашняя папка. sed "s|что|на что|" — замена по регулярному выражению: ^Exec=.* — строка, начинающаяся с Exec=. > — записать вывод в файл, 2>/dev/null — выбросить сообщения об ошибках. tar -czf архив.tar.gz папка — упаковать папку в сжатый архив (c — создать, z — сжать gzip, f — в файл).

11.6. Самопроверка --selftest

Собранная программа запускается с ключом --selftest: открывает окно, через 1,5 с делает расчёт, печатает «selftest ok» и выходит с кодом завершения 0 (успех) или 1 (ошибка). Код завершения — число, которое программа возвращает системе; сборка проверяет его. Так ловятся ошибки, которых нет при запуске из исходников: забытая библиотека, не найденный модуль Qt. Ключ убирается из списка аргументов, прежде чем передать его Qt.

$p = Start-Process $exe -ArgumentList '--selftest' -Wait -PassThru
if ($p.ExitCode -ne 0) { throw "selftest failed" }

На Windows программа с окном (--windowed) не ждёт завершения в консоли, поэтому её запускают через Start-Process -Wait -PassThru: дождаться и вернуть объект процесса с кодом завершения; -ne — «не равно»; throw — ошибка, которая остановит сборку.

Часть 13. Как сделаны методички

Методички — не документы Word, а страницы HTML, которые программа tools/build_docs.py превращает в PDF. Это позволяет брать код, формулы, рисунки и снимки прямо из программы.

  1. Снимки окна: tools/docs_shots.py запускает программу без экрана (offscreen), выставляет нужные параметры, делает grab() и сохраняет PNG. На снимок главного окна дорисовываются номера-выноски.
  2. Шаблоны docs/src/*.html — обычный HTML (язык разметки веб-страниц: <h1> заголовок, <p> абзац, <table> таблица) плюс особые метки:
    • <code ref="physics.airy"/> — модуль ast разбирает physics.py как дерево, находит функцию airy, берёт её строки из файла; pygments раскрашивает код;
    • <eq>…</eq> и текст между знаками доллара — формулы в записи LaTeX (язык формул: \frac{a}{b} — дробь, \sqrt{x} — корень, \lambda — λ). latex2mathml переводит их в MathML — язык формул, который браузер рисует сам;
    • <fig name="…"/> — рисунок SVG из tools/docs_figures.py. SVG — векторная картинка, записанная текстом (линии, кривые, надписи), чёткая при любом увеличении. Графики на рисунках считаются функциями physics.py;
    • <py name="…"/> — таблица, посчитанная tools/docs_tables.py (ответы для 30 вариантов).
  3. Метки заменяются регулярными выражениями (re.sub): шаблон вроде <code\s[^>]*/> находит все такие места, функция подставляет готовый HTML. Уже вставленные куски временно заменяются метками-заглушками, чтобы знак доллара в коде не приняли за формулу.
  4. PDF: библиотека Playwright управляет браузером Chromium без окна: открывает страницу и печатает её в PDF формата A4 с полями и номерами страниц. Оформление (шрифты, отступы, как в методичках МГТУ) — в style.css (CSS — язык оформления веб-страниц).

Часть 14. Если что-то не работает

ModuleNotFoundError: No module named 'PyQt6' (или numpy)
Библиотека не установлена в тот Python, которым запускаете. python -m pip install -r requirements.txt — именно через python -m pip, чтобы pip был того же Python.
Windows 7: PyQt6 не ставится или программа из исходников не запускается
Qt 6 не работает на Windows 7. Нужен Python 3.8 и pip install -r requirements/win7.txt. Или готовый exe.
Windows 7: «api-ms-win-crt-runtime-l1-1-0.dll не найдена»
Нет UCRT. В готовой сборке она внутри; если сборка сделана без неё — поставить обновление KB2999226.
Одиночный exe долго стартует
Он распаковывается при каждом запуске (часть 11.2). Используйте portable-версию.
Антивирус ругается на exe
Загрузчик PyInstaller иногда ложно принимают за вирус, потому что он распаковывает код во временную папку. Помогает portable-версия или добавление в исключения.
macOS: «программа повреждена и не может быть открыта»
xattr -cr "/Applications/Fabry-Perot.app" в Терминале (часть 11.4).
Linux: «could not load the Qt platform plugin "xcb"»
Не хватает системной библиотеки. sudo apt install libxcb-cursor0 libxkbcommon-x11-0. Запуск с QT_DEBUG_PLUGINS=1 ./FabryPerot покажет, какой именно.
Всё мелкое или мыльное на экране с масштабом
Проверьте масштаб в настройках экрана; программа сама подстраивается (часть 6.10). В Qt 5 можно задать QT_SCALE_FACTOR=1.25.
Хочу сбросить все настройки
Удалить файл FabryPerot.ini (часть 6.8). Программа начнёт с первого примера.
Лабораторная «застряла» после перезапуска
Так задумано: незавершённая работа продолжается. Кнопка «Завершить» выключает режим.
Тесты падают с ошибкой про дисплей
Задайте QT_QPA_PLATFORM=offscreen. Для проверки старой версии Qt — FABRY_QT=5.
Сборка на GitHub красная
Actions → запуск → задание с красным крестиком → шаг с ошибкой: там полный текст. Чаще всего это упавший тест: его имя и значения видны в выводе pytest.
