# Интерферометр Фабри — Перо

Интерактивная модель интерферометра Фабри — Перо (проект СЭЛФ, МГТУ им. Н. Э. Баумана).

Задаёте длину волны λ, зазор между зеркалами d, отражение R и другие параметры. Программа сразу
строит график пропускания T(λ), картину колец и разрез колец по радиусу. По графикам она сама
измеряет расстояние между пиками Δλ, ширину пика w, резкость и разрешающую способность, а рядом
показывает значения по формулам. Работает без интернета.

## Как пользоваться

**Параметры (слева).** У каждой величины указаны единицы и допустимые значения.
Если вести ползунок, картина меняется сразу. Если ввести число в поле (Enter, колёсико мыши,
стрелки ↑ ↓), картина плавно «переплывает» от старого значения к новому: видно, как кольца
расходятся или сжимаются, а пики сдвигаются.

**Готовые примеры** переключаются тоже плавно:

- гелий-неоновый лазер 632,8 нм;
- натриевый дублет 589,0 и 589,6 нм: две линии видны как двойные кольца;
- предел разрешения, где δλ чуть больше ширины пика w;
- зелёный лазер с зеркалами R = 0,98: очень узкие пики;
- стеклянный эталон с n = 1,5;
- зеркала с потерями A = 0,02: пики ниже 1;
- плохие зеркала с R = 0,3: широкие размытые пики.

**Графики.** При наведении мыши показываются значения под курсором. Колёсико меняет масштаб по
горизонтали, перетаскивание сдвигает график, двойной щелчок возвращает его целиком.

**Кольца.** При наведении на кольца видны радиус r, порядок интерференции m и яркость. Тот же
радиус отмечается пунктиром на разрезе, и наоборот. Переключатель «свечение» добавляет мягкий
ореол, как на фотографии.

**Анимация.** Кнопка «Двигать зеркало» (или пробел) плавно сдвигает зеркало. Каждые λ/2 в центре
рождается новое кольцо, а пики бегут по графику.

**Вторая линия.** Включите её и уменьшайте δλ, пока двойные кольца не сольются. Внизу справа
будет написано, различает ли прибор линии.

**Измерения (справа).** Крупно показаны значения «по графику», под ними — «по формуле».
Цветной значок показывает расхождение между ними. Если навести мышь на строку таблицы, появится
формула.

**Лабораторная работа.** Кнопка «Лабораторная»: ввести фамилию, группу и номер варианта (1–30, выдаёт
преподаватель). Длина волны и поглощение зеркал скрываются, их нужно определить по измерениям; результаты программы
тоже скрыты. Справа открывается журнал измерений: **правый щелчок** по графику, разрезу или кольцам записывает
точку в выбранную серию, журнал проводит прямую методом наименьших квадратов и выдаёт результат с погрешностью.
Незавершённая работа продолжается после перезапуска.

**Линза и экран в лабораторной.** Фокусное расстояние линзы выбирается из набора (100–500 мм), а экран нужно
самому поставить в фокус: вне фокуса кольца размываются кружком диаметром D·|L − f|/f.

**Сохранение.** Кнопки вверху:

- снимок окна в PNG (Ctrl+S);
- картина колец 2048 × 2048 для отчёта (Ctrl+Shift+S);
- таблица CSV для Excel (Ctrl+E);
- копирование таблицы в буфер обмена (Ctrl+Shift+C).

Также доступны тёмная и светлая тема (Ctrl+T), справка (F1) и полноэкранный режим (F11).
Параметры, тема и размер окна запоминаются до следующего запуска.

## Скорость на слабых компьютерах

Программа рассчитана и на старые машины, например Core i5 второго поколения со встроенной графикой.
Видеокарта не нужна: всё рисует процессор.

- **Графики** рисуются по формуле, а не по набору точек. Для каждого столбца пикселей точно
  находятся наибольшее и наименьшее значение функции Эйри (`physics.airy_range`), и кривая
  с заливкой и свечением собирается одной картинкой средствами numpy. Время кадра не зависит
  от того, сколько пиков на графике, и узкий пик не пропадает между точками.
- **Кольца** тоже считаются по формуле. Средняя яркость пикселя, в который могут попасть сотни
  тонких колец, вычисляется по первообразной функции Эйри (`physics.airy_mean`). Это несколько
  тысяч вычислений на картинку вместо миллионов точек.
- **Измерения «по графику»** — честный поиск пиков, но на разумном числе точек: десятки тысяч,
  с уточнением вблизи каждого пика, как под микроскопом.
- Оправа окуляра, сетка и подписи рисуются один раз и хранятся готовой картинкой. Движение
  мыши перерисовывает только курсор.

Один кадр (пересчёт и перерисовка всех графиков) занимает около 10 мс на одном ядре
современного процессора при любых параметрах. Раньше в тяжёлых режимах было до 350 мс.
Плавные переходы идут по времени, а не по кадрам: даже на медленной машине переход длится
те же 0,85 с, просто кадров в нём меньше.

## Запуск из исходников

Нужен Python 3.8 или новее.

```bash
pip install -r requirements.txt       # numpy и PyQt6
python run.py                         # или: python -m fabry_perot
```

На Windows 7, 8 и 8.1 Qt 6 не работает, поэтому там нужен Python 3.8 и
`pip install -r requirements/win7.txt` (PyQt5). Программа сама подключит PyQt5, если PyQt6 нет.

Проверки: `pip install pytest && python -m pytest tests`

## Как собираются программы

Всё собирается автоматически в GitHub Actions (`.github/workflows/build.yml`) при каждом push.

- **Windows**: Python 3.8 (32 бит) + PyQt5 5.15 + PyInstaller 5.13. Это последние версии,
  которые работают на Windows 7. Собирается два варианта: один `.exe` и portable-папка в `.zip`.
  Внутрь кладётся библиотека UCRT, поэтому обновления Windows 7 ставить не нужно.
- **macOS**: Python 3.12 + PyQt6 6.7, приложение `.app` в образе `.dmg`. Отдельные сборки для
  Apple Silicon и для Intel.
- **Linux**: Python 3.11 + PyQt6 6.7, собирается на Ubuntu 22.04. Нужные библиотеки Qt лежат
  внутри файла.

Прежде чем выложить файл, каждая сборка проходит тесты и запускается с ключом `--selftest`.
Для выпуска версии достаточно отправить тег:
`git tag v2.0.0 && git push origin v2.0.0`. Файлы появятся в Releases.
